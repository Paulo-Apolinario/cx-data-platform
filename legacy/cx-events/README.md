# Experimento anterior: eventos de experiência do cliente

Este diretório preserva o código do experimento original para consulta histórica.
Ele não integra a aplicação de gestão de obras, não é iniciado pelos comandos da
raiz e não deve ser utilizado em produção. A documentação PDF aqui é histórica.

A aplicação atual não depende de Python, RabbitMQ ou Docker. Os arquivos com
credenciais e os arquivos de contêiner foram retirados. As credenciais publicadas
no histórico devem ser substituídas caso tenham sido utilizadas.
