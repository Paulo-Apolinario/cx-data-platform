# CX Data Platform

Plataforma de Engenharia de Dados construída para simular ingestão,
processamento e análise de dados de experiência do cliente.

## Tecnologias
- Python
- RabbitMQ
- PostgreSQL
- Docker
- Apache Airflow (em breve)

## Arquitetura
- Ingestão batch e streaming
- Mensageria com RabbitMQ
- Data Lake em Parquet
- Data Warehouse analítico
- Governança e LGPD

Projeto desenvolvido para fins de estudo e portfólio profissional.
